## Getting Started

Before you begin, please make sure to **add the required API keys** to your `.env` file:

- Get your OpenAI API key from: [OpenAI Console](https://platform.openai.com/)

Add the key to your `.env` file as follows:

``` .env
OPENAI_API_KEY=your_openai_api_key
OPENAI_CODE_MODEL=gpt-4o-mini
```

## Install & Run

From the `lovable-ui` directory, install all dependencies and start the development server:


```bash
cd lovable-ui

npm install
npm run dev
```

This will launch the app locally (by default at http://localhost:3000).
